# cx — etiquetas QR das caixas de insumos

Página aberta pelo QR code das etiquetas das caixas A, B e C do painel de insumos da oficina.

- `https://diogokramp.github.io/cx/#A12` mostra a caixa A12: item, código TOTVS, status de pedido e o botão **Solicitar item**.
- O pedido vai para o formulário "Solicitação de insumos – Oficina" (Google Forms do PCM).
- `data.json` traz os itens e o status das SAs, atualizado junto com o painel.
